    Local Settings

    For DISABLE this window while wallpaper start • Open General Settings • UnCheck NEWS WINDOW

    The Local Settings are the settings saved on local storage like windows positions on the screen or calendar information.

    This settings cannot be shared just posting the wallpaper preset like we normally do so for to do this we have to follow some steps.


    This is an simple example how looks the windows positions local settings:


    panelCalendar#div#1477,1,false,1

    The text line contains the window name, visibility, scale and X-Y position information

    Allowing the wallpaper to interpret the information and share it using the presets.


    In order to obtain the positions of the windows and be able to share them in a preset,

    What we must do is go to the Settings Panel, click on the Copy Local Settings Button.


    Once the positions have been copied on clipboard, we must:


    • Go to the Wallpeper Properties in Wallpaper Engine.

    • Select the 🌠 General Settings section.

    • Paste the text in the Settings text input.


    Once the window positions have been pasted in the Settings, the preset can be
    shared including the windows positions.


    The Widgets Project Extension its an open source executable which works as an intermediary between the wallpaper and your pc and allows you to display information like CPU usage, RAM usage, or put your ToDo-Notes in to the wallpaper.



    • Download Link: Coppy to Clipboard


    • Video Tutorial: Coppy to Clipboard


    • Any Question? Join our Discord


    The script features a Configuration Menu accessible from the system tray, letting you adjust settings like wallpaper directory and location for weather updates, creating a personalized experience.


    You can manage Personal Notes directly on the wallpaper. Notes are stored in the Extension Settings.json for easy viewing and management.


    The script monitors CPU, RAM and Battery Charge via psutil, recording data for real-time system performance updates on the wallpaper.


    The Calendar Widget has an option that allows you to import your own Calendar.

    This functionality has some errors but allows you to display the events from example Google Calendar within the wallpaper calendar.


    In order to use this functionality, the following steps must be followed:

    • Download your Calendar in .ics format.

    • Go to the Widgets Menu (settings) and Click the Import Calendar button.

    • Select the calendar.ics to add and thats it.


    If you want to Delete the added calendar, you must go to the Local Settings Panel and press the Reset button.


    Another thing to mention is that neither the calendar or windows positions can be shared through the Local Settings or Presets, these only work to share the information of the windows such as their position, scale and visibility.

    As for the Weather Widget, it allows you to view humidity, percentage of precipitation, wind speed, and the amount of rain that fell.

    It will also allow you to see the weather in the coming weeks.


    In order to use this functionality, the following steps must be followed:

    • Go to the Wallpaper Properties in Weather.

    • Define your Longitude and Latitude according to your Location.

    • And thats it, the weather data will be updated every 1h and you can manually refresh it in the Settings Panel.


    • Api URL: open-meteo.com
